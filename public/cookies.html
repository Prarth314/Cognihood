Browser storage

Cookies and Local Storage Notice

CogniHood currently uses browser storage for necessary sessions and preferences. Vercel Web Analytics is configured as a cookieless analytics service.

Effective: October 28, 2026 · Version: 2026-10-28

Current technologies

TechnologyPurposeDuration/control

Cookies

The current CogniHood application does not intentionally set advertising, cross-site tracking, or marketing cookies. Authentication behavior may vary if Supabase changes its client implementation or if a future feature is introduced. This notice must be updated before any non-essential cookie is deployed.

Analytics details

Vercel Web Analytics may process a timestamp, page path, referrer, filtered query parameters, approximate city/country derived from the request, browser, operating system, and device category. CogniHood must not place email addresses, account identifiers, tokens, trip identifiers, or other personal information in public URL paths or analytics events.

Your controls

  • Sign out to end the active application session.
  • Use browser settings to clear site data, local storage, and IndexedDB.
  • Block site storage through browser controls, understanding that authentication and preferences may stop working.
  • Use private-browsing mode to reduce persistence on a shared device.

No consent banner is currently displayed because the implemented analytics is cookieless and the remaining storage supports user-requested functionality. Regional law and future features may require a consent-management platform; that determination must be reviewed before broader commercial launch.

Changes

If CogniHood adds advertising, marketing tags, session replay, additional analytics, or non-essential cookies, this notice and the consent experience will be updated before deployment.
