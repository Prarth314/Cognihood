# Signal contract — research prototype

This contract describes code, not validated human performance. `faceDetected` means the SDK returned finite bilateral eye geometry and a finite transformation matrix. It is not identity recognition, an independently calibrated landmark-confidence probability or proof of attention. The SDK processes one face; multiple-person attribution is unsupported. Missing matrix/geometry is unavailable evidence.

## Pipeline and boundaries

Capture scheduled at most 10 Hz → one transferable bitmap in flight → SDK inference in classic worker (GPU then CPU) → captured wall-clock timestamp → ordered, age- and count-bounded buffer → temporal indicators → qualified UI and bounded derived session summary. Inference uses monotonic `performance.now()`; windowing uses capture `Date.now()`. Nonmonotonic capture times and delayed results (>500 ms) are rejected. Do not confuse provider completion time with capture time.

Local main-thread compatibility mode remains available. Its single SDK model is cached for the page lifetime; a pending SDK initialization cannot cancel its internal download. Worker initialization is abortable. Camera permission requests themselves cannot be canceled by the browser API; a late grant is stopped without attachment. Camera switching is not implemented; retry reacquires the default user-facing device. Track end/mute, hidden tabs, unmount and session exits invalidate current evidence. No bitmap queue is accumulated. Screen wake-lock is best effort.

Optional cloud requests carry a per-session receipt and have an 18 s client / 12 s server timeout. Disabling cloud, leaving or hiding the session aborts/invalidates pending client work. A request already received by the server cannot be unsent. A successful response contributes bounded, separately labelled commentary only, rebased on current local evidence; it adds no scoring sample. No commentary is accepted when local evidence has disappeared.

Session summary acceptance still requires ≥30 s and ≥3 score observations, at most one score every 3 s, finite/eligible local evidence, and server RPC validation. Timeline/event arrays remain bounded. A session's consent-at-start flag currently records permission to use cloud, not a provider-success count; no usage/billing conclusion should be drawn from that legacy flag. Aggregated session means remain sample-weighted; they are not exposure-adjusted clinical endpoints. No automatic retention deletion is configured; owner deletion/export is available.

Audio cues have an 8 s cooldown; one urgent cue may interrupt a calm cue, but repeated urgent cues are also bounded. Leaving/hiding cancels speech. No screen interaction or vehicle-control command is required while monitoring. All human demos/testing must be stationary.

Threshold values are retained. Changes in this milestone concern evidence validity, denominator consistency, stale-result ordering and claims; none is a newly validated physiological threshold. See `RESEARCH_WORKFLOW.md` for evidence classifications and validation dependencies.
